# YouTube Web Page

A YouTube-inspired web page built using HTML and CSS. This project focuses on recreating the layout and visual structure of a modern video streaming interface.

## Features

- Responsive YouTube-style layout
- Navigation sidebar
- Search bar
- Video thumbnail grid
- Channel information
- Video titles and metadata
- Custom icons and images
- CSS-based styling and layout

## Technologies Used

- HTML5
- CSS3
